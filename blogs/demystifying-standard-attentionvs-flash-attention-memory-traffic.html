Memory Traffic in Attention: Standard Attention vs. FlashAttention

A deep dive into GPU memory hierarchies (HBM vs. SRAM), IO-awareness, and the mathematical derivation of FlashAttention's \(\mathcal{O}(N^2 d^2 / M)\) memory footprint.

1. Notation and Key Dimensions

  • \(N\): Sequence length (number of tokens).
  • \(d\): Head dimension (e.g., 64 or 128).
  • \(M\): Fast on-chip SRAM capacity per Streaming Multiprocessor (SM), measured in number of scalar elements.
  • Inputs / Outputs: \(Q, K, V, O \in \mathbb{R}^{N \times d}\).
  • Intermediate Attention Matrices: Attention scores \(S, P \in \mathbb{R}^{N \times N}\).

2. Standard Attention Memory Traffic

Standard multi-head attention executes as sequential, discrete GPU kernel launches. It repeatedly reads and writes full \(N \times N\) intermediate matrices to and from slower High Bandwidth Memory (HBM).

HBM                    SRAM (Compute)                    HBM
---                    --------------                    ---
[Q, K]       ----->    Compute S = Q K^T      ----->    [S (N x N)]
[S]          ----->    Compute P = softmax(S) ----->    [P (N x N)]
[P, V]       ----->    Compute O = P V        ----->    [O (N x d)]

Step-by-Step HBM Data Transfers

  1. Score Matrix (\(S = Q K^T\)):
    • Read \(Q\) (\(Nd\)) and \(K\) (\(Nd\)) \(\rightarrow 2Nd\)
    • Write \(S\) to HBM \(\rightarrow N^2\)
  2. Softmax Normalization (\(P = \text{softmax}(S)\)):
    • Read \(S\) from HBM \(\rightarrow N^2\)
    • Write normalized probabilities \(P\) to HBM \(\rightarrow N^2\)
  3. Context Matrix (\(O = P V\)):
    • Read \(P\) (\(N^2\)) and \(V\) (\(Nd\)) \(\rightarrow N^2 + Nd\)
    • Write output \(O\) to HBM \(\rightarrow Nd\)
Total Standard HBM Traffic: $$\text{Total}_{\text{Standard}} = \underbrace{4Nd}_{\text{I/O (Q, K, V, O)}} + \underbrace{4N^2}_{\text{Intermediates (S, P)}} = \mathcal{O}(Nd + N^2)$$

When \(N \gg d\), the \(4N^2\) term completely dominates, rendering execution memory-bandwidth bound.

3. FlashAttention Memory Traffic

FlashAttention utilizes kernel fusion and tiling paired with the Online Softmax algorithm to compute attention without ever materializing the \(N \times N\) matrices into HBM.

Tiling Budget and Block Size

To compute attention inside SRAM, the blocks of \(Q_i\), \(K_j\), \(V_j\), and the accumulator \(O_i\) must fit within SRAM capacity \(M\) simultaneously:

$$\text{SRAM footprint} \approx B_r \cdot d + B_c \cdot d + B_c \cdot d + B_r \cdot d = 2d(B_r + B_c) \le M$$

Setting \(B_r \approx B_c = B\):

$$4 \cdot B \cdot d \le M \implies B \approx \frac{M}{4d}$$

Derivation of the \(\mathcal{O}\left(\frac{N^2 d^2}{M}\right)\) Term

Consider the outer loop over \(Q\) tiles and inner loop over \(K, V\) tiles:

# Total blocks along sequence length
num_blocks = N / B  # where B ≈ M / (4d)

for i in range(num_blocks):  # Outer Loop (over Q blocks)
    # 1. Load Q_i into SRAM (size: B x d)

    for j in range(num_blocks):  # Inner Loop (over K, V blocks)
        # 2. Load K_j, V_j into SRAM (size: 2 * B * d)
        # 3. Compute partial tile & update accumulator in SRAM

    # 4. Write final O_i back to HBM (size: B x d)
  1. Outer Loop Iterations: $$\text{Iterations} = \frac{N}{B} \approx \frac{N}{\frac{M}{4d}} = \frac{4Nd}{M}$$
  2. Inner Loop Transfers: In every single outer iteration, the inner loop sweeps through the entire sequence of \(K\) and \(V\) matrices (\(2Nd\) elements total).
  3. Total Reads of \(K\) and \(V\): $$\text{Total Reads} = (\text{Outer Iterations}) \times (\text{Size of } K \text{ and } V) = \left(\frac{4Nd}{M}\right) \times (2Nd) = \frac{8N^2 d^2}{M} = \mathcal{O}\left(\frac{N^2 d^2}{M}\right)$$
Total FlashAttention HBM Traffic: $$\text{Total}_{\text{Flash}} = \underbrace{2Nd}_{\text{Read Q, Write O}} + \underbrace{\mathcal{O}\left(\frac{N^2 d^2}{M}\right)}_{\text{Repeated reads of K, V}} = \mathcal{O}\left(Nd + \frac{N^2 d^2}{M}\right)$$
