Understanding Prefill FLOPs: Multi-Head Attention vs. Sliding Window Attention

LLM Architecture & Deep Learning Systems • Derivation & Analysis

When scaling Large Language Models (LLMs) to massive context windows, computational complexity becomes the primary bottleneck during prompt ingestion (the prefill phase). In this post, we break down the exact Floating Point Operations (FLOPs) required for standard causal Multi-Head Attention (MHA) and Sliding Window Attention (SWA) from first principles.

1. Mathematical Foundations: The FLOP Count Rule

Let's establish the fundamental arithmetic rule for matrix multiplication:

  • A single dot product of two vectors of dimension \(d\) requires \(d\) multiplications and \(d - 1\) additions: $$\text{Cost} = d + (d - 1) \approx 2d \text{ FLOPs}$$
  • Multiplying a matrix \(A \in \mathbb{R}^{M \times K}\) with a matrix \(B \in \mathbb{R}^{K \times N}\) produces an \(M \times N\) matrix where every element requires a length-\(K\) dot product: $$\text{Total FLOPs} = (M \times N) \times 2K = 2MNK$$

2. Variables & Notation

  • \(N\): Input sequence length (prompt length)
  • \(W\): Sliding window size (\(W \le N\))
  • \(d\): Model hidden dimension
  • \(h\): Number of attention heads
  • \(d_k\): Head dimension, where \(d_k = \frac{d}{h}\)

3. Step 1: Linear Projections (\(Q, K, V, O\))

Before attention scores are calculated, the input representation \(X \in \mathbb{R}^{N \times d}\) must be projected into Query, Key, and Value spaces, followed by the final output projection:

  • Query Projection (\(X W_Q\)): \((N \times d) \times (d \times d) \rightarrow \mathbf{2Nd^2}\) FLOPs
  • Key Projection (\(X W_K\)): \((N \times d) \times (d \times d) \rightarrow \mathbf{2Nd^2}\) FLOPs
  • Value Projection (\(X W_V\)): \((N \times d) \times (d \times d) \rightarrow \mathbf{2Nd^2}\) FLOPs
  • Output Projection (\(\text{Out} \cdot W_O\)): \((N \times d) \times (d \times d) \rightarrow \mathbf{2Nd^2}\) FLOPs

Projection Total: \(4 \times (2Nd^2) = \mathbf{8Nd^2}\) FLOPs.
This cost is identical for both standard MHA and Sliding Window Attention.

4. Step 2: Attention Core Computation

A. Standard Causal Multi-Head Attention (MHA)

In autoregressive causal language modeling, token \(i\) only attends to prior tokens \(1 \le j \le i\). The total number of token-to-token interactions across the sequence is:

$$\sum_{i=1}^{N} i = \frac{N(N + 1)}{2} \approx \frac{N^2}{2} \text{ pairs per head}$$
  • Score Computation (\(QK^T\)):
    $$\text{FLOPs}_{QK^T} = h \times \left(\frac{N^2}{2}\right) \times 2d_k = h \times \frac{N^2}{2} \times 2\left(\frac{d}{h}\right) = \mathbf{N^2 d}$$
  • Value Blending (\(A \cdot V\)):
    $$\text{FLOPs}_{AV} = h \times \left(\frac{N^2}{2}\right) \times 2d_k = \mathbf{N^2 d}$$

Total Core MHA FLOPs: \(N^2 d + N^2 d = \mathbf{2N^2 d}\) (Confused by the \(N^2 d\) derivation? See the Step-by-Step Causal Breakdown below.)

B. Sliding Window Attention (SWA)

In SWA, a token can look back at at most \(W\) preceding tokens:

  • The first \(W\) tokens look at \(1, 2, \dots, W\) tokens: \(\frac{W^2}{2}\) pairs
  • The remaining \((N - W)\) tokens look at exactly \(W\) tokens: \((N - W)W\) pairs
  • Total token pairs: \((N - W)W + \frac{W^2}{2} = NW - \frac{W^2}{2} \approx \mathbf{NW}\) (when \(N \gg W\))
  • Score Computation (\(QK^T\)):
    $$\text{FLOPs}_{QK^T} \approx h \times (NW) \times 2d_k = 2NW(h \cdot d_k) = \mathbf{2NWd}$$
  • Value Blending (\(A \cdot V\)):
    $$\text{FLOPs}_{AV} \approx h \times (NW) \times 2d_k = \mathbf{2NWd}$$

Total Core SWA FLOPs: \(2NWd + 2NWd = \mathbf{4NWd}\)

Appendix: Step-by-Step Breakdown of \(N^2 d\) in Causal Attention

A common question is: Why is causal attention \(N^2 d\) instead of \(2N^2 d\)? Let's walk through the math step-by-step.

1. Why is the sum \(\frac{N(N+1)}{2} \approx \frac{N^2}{2}\)?

In autoregressive language models, tokens cannot look forward into future tokens. Each token only attends to preceding tokens and itself:

  • Token 1: attends to \(\{1\}\) \(\rightarrow\) 1 dot product
  • Token 2: attends to \(\{1, 2\}\) \(\rightarrow\) 2 dot products
  • Token 3: attends to \(\{1, 2, 3\}\) \(\rightarrow\) 3 dot products
  • ...
  • Token \(N\): attends to \(\{1, 2, \dots, N\}\) \(\rightarrow\) \(N\) dot products

Summing this series gives: $$\text{Total dot products per head} = \sum_{i=1}^{N} i = \frac{N(N + 1)}{2} \approx \frac{N^2}{2}$$ Visual intuition: An \(N \times N\) matrix has \(N^2\) total cells. Causal masking zeros out the upper triangle, computing only the lower triangle (\(\approx \frac{N^2}{2}\) elements).

2. FLOPs per Single Head

Each dot product between a query vector and a key vector of length \(d_k\) costs \(2d_k\) FLOPs (\(d_k\) multiplications and \(d_k - 1\) additions): $$\text{FLOPs}_{\text{head}} = \left(\frac{N^2}{2}\right) \times 2d_k = N^2 d_k$$

3. Aggregating Across All \(h\) Heads

To get the total cost across all \(h\) heads in the layer: $$\text{Total FLOPs}_{QK^T} = h \times (N^2 d_k) = N^2 (h \cdot d_k)$$

Since the total embedding dimension is defined as \(d = h \times d_k\), substituting gives the final result: $$\mathbf{\text{FLOPs}_{QK^T} = N^2 d}$$

  • Unmasked / Bidirectional Attention (e.g., BERT): All \(N^2\) cells computed \(\rightarrow \mathbf{2N^2 d}\) FLOPs.
  • Causal / Autoregressive Attention (e.g., GPT, LLaMA): Lower triangle only (\(\frac{N^2}{2}\)) \(\rightarrow \mathbf{N^2 d}\) FLOPs.
